# JARVIS Skills & Tools Repository

A centralized, isolated directory dedicated solely to the **Agent Skills** and **Canonical Tools** of the JARVIS ecosystem.

```
skills_and_tools/
├── README.md                           # Master overview and navigation
├── skills/                             # Agent behavioral & engineering skills
│   ├── README.md                       # Skills matrix & trigger index
│   ├── awwwards-winner/                # Editorial & WebGL visual design
│   ├── caveman/                        # Ultra-terse output mode
│   ├── find-skills/                    # Automated skill discovery
│   ├── hallmark/                       # Structural anti-slop design & palettes
│   ├── impeccable/                     # UI audit & craft floor enforcement
│   ├── jarvisbrowser/                  # Dynamic on-device HTML5 app generator
│   ├── no-ai-slop/                     # Elimination of generic AI visual patterns
│   ├── openwolf/                       # Persistent agent cross-session memory
│   ├── screencapture/                  # Fast text hierarchy & virtual taps
│   ├── token-efficient/                # High-efficiency token discipline
│   ├── ui-ux-pro-max/                  # Complete design tokens & guidelines
│   ├── unlazy/                         # Autonomous depth-tree task completion
│   ├── unslop-ui/                      # Interface polish & layout cleanups
```

## 🧠 Skills (14 Modules)
High-level agent capabilities and behavioral rules guiding LLM interaction, UI generation, frontend review, and task execution.
See [`skills/README.md`](./skills/README.md) for trigger words and documentation.
