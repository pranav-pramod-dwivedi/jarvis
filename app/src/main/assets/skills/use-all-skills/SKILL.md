# Use-All-Skills: The Unified Agent Orchestrator

This command forces the agent to orchestrate and apply **each and every installed skill** to guarantee world-class execution without slop or token waste.

## Execution Chain

Whenever creating UI, writing software, or responding to complex requests:

```
[User Request]
       │
       ▼
1. TOKEN EFFICIENCY & COMPRESSION (caveman + token-efficient)
   - Strip pleasantries, greetings, restated questions, and fluff.
   - Fire tools immediately without meta-narration.
       │
       ▼
2. MEMORY & CONTINUITY (openwolf)
   - Read persistent project conventions from .wolf/ or workspace memory.
   - Avoid re-reading cached files.
       │
       ▼
3. STRUCTURAL ARCHITECTURE (hallmark)
   - Demand structural variety. Never repeat the same standard hero → 3-card grid → CTA rhythm.
   - Lock design tokens (OKLCH/hex variables). Never improvise inline colors.
   - Mobile-first responsiveness across 320/375/414/768px.
       │
       ▼
4. ANTI-SLOP FILTER (unslop-ui / no-ai-slop)
   - Ban generic purple/indigo gradients (#8B5CF6, violet-600).
   - Ban shadcn-default card copy-pastes, pill badges over headings, and generic Inter/Geist defaults.
   - Ban em-dashes and filler copy ("unlock", "seamless", "supercharge").
       │
       ▼
5. DESIGN SYSTEM RIGOR (ui-ux-pro-max)
   - Apply mathematical spacing grids (4px/8px scale).
   - Enforce WCAG AA contrast (minimum 4.5:1 for body copy).
   - Establish consistent component interaction states (hover, active, focus).
       │
       ▼
6. AWWWARDS-WINNER CREATIVE ENGINE (awwwards-winner)
   - Editorial & brutalist layouts with intentional typography contrast.
   - 60fps WebGL/Canvas micro-interactions and realistic cubic-bezier easing (`cubic-bezier(0.16, 1, 0.3, 1)`).
   - Think like an elite creative studio, not a generic SaaS template.
       │
       ▼
7. CRAFT FLOOR & POLISH (impeccable)
   - Verify in bounded passes. Inspect desktop + mobile layout simultaneously.
   - Implement authentic micro-interactions, delightful empty states, and resilient error recovery.
       │
       ▼
8. RUNTIME DISPATCH (jarvisbrowser)
   - Deploy as a self-contained, offline-first, hardware-accelerated interactive web-app.
   - Launch immediately on device with accompanying voice narration via `window.jarvis.speak(...)`.
```

## Slash Command / Directive Usage
- `/use-all-skills`: Activates the full multi-skill chain for the current task.
